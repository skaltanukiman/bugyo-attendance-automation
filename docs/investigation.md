## サンプルExcel

両ファイルともBIFF形式の `.xls`、シートは `印刷用シート(協力会社用)` の1枚。使用領域は79行×30列で、欄外に祝日マスター等があります。欄外や作業内容、個人情報は解析対象外です。

| 項目 | 実セルと解釈 |
| --- | --- |
| 日付 | B10:B40が日番号、C10:C40がExcel日付シリアル（表示は曜日） |
| 作業開始 | D/E列の整数の時・分 |
| 作業終了 | F/G列の整数の時・分 |
| 総時間 | H/I列の時・分（出退勤差分と照合） |
| 休憩 | J/K列の時・分 |
| 実働 | L/M列の時・分。見出しは「実動時間」 |
| 月合計 | L42/M42の時・分。明細合計と照合 |
| ヘッダー | 8行目のB:Mを照合。結合された一文字列ではなく分割セル |

架空の変換例として、D=10,E=0,F=18,G=45,J=1,K=0,L=7,M=45の場合、開始10:00、終了18:45、休憩1時間、実働7.75時間になります。日付の真値をファイル名の年月と全行で照合します。

原本の対象年月、休暇記述や勤務空欄の具体的な日付、出退勤時刻、月間集計値は掲載しません。作業内容欄に休暇記述があっても自動有休認定はせず、勤務時間の有無と利用者の明示指定を分けて扱います。

末尾の非存在日行は空欄です。月合計は計算済み値を読み、独立に集計した実働と比較します。原本での照合は完了済みであり、継続的な自動テストには架空データを使用します。
